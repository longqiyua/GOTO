GOTO 开源声明

GOTO Page 是 GitHub Pages 的文档与交互预览源；Android 端使用同一份页面资源镜像。GOTO Engine、GOTO Base、GOTO Where 是已定档的冻结组件，页面只负责展示、编排与调用，不改变其内部实现。

  • 项目代码按仓库根目录 LICENSE 中的 AGPL-3.0-only 条款发布。
  • 修改后的网络版本应向交互用户提供完整对应源代码，并保留本声明、版权与第三方许可文本。
  • 第三方库、字体、服务和可选数据集仍以其权利人的原始条款为准；本页记录它们的来源、分发范围与使用边界。
