# GOTO

> 一次输入，直接抵达。GOTO 是一款本地优先的应用搜索与启动工具：不需要先想起应用放在哪一页，只要说出你记得的名字、拼音、缩写或关键词，就能更快打开它。

## 先用 30 秒理解 GOTO

GOTO 的首页只有一个核心动作：点击搜索框，输入你想打开的应用，然后选择结果。你不必记住应用图标的位置，也不必先打开一个复杂的菜单。

<button class="doc-inline-demo" data-preview-action="home-ready">在手机预览中查看首页</button>

1. **点击搜索框**：搜索框会向下展开，为结果和最近使用留出稳定空间。
2. **输入记得住的内容**：支持应用名称、英文、中文、拼音、缩写、标签和常见的模糊输入。
3. **确认结果**：结果卡片会尽量展示真实应用名称和系统图标；没有可用图标时使用统一的中性灰占位，不伪造图标。
4. **点击启动**：在 Android 应用中，GOTO 会通过系统能力启动真实应用；网页预览只展示对应的交互状态。

## GOTO 能帮你做什么

### 更快找到应用

你可以输入“chrome”、中文名、拼音片段，或者只记得的一部分。GOTO 会把结果整理成易读的候选卡片，把当前最可能的目标放在更容易确认的位置。

输入没有匹配结果时，页面会保持统一的空状态尺寸和位置，不会因为文案长度或动画突然跳动。你可以继续修改输入，也可以返回首页查看最近和常用入口。

<button class="doc-inline-demo" data-preview-action="home-search" data-preview-query="chrome">在手机预览中试试搜索</button>

### 最近与常用，跟着你变化

首页卡片不是固定示例。最近区域优先呈现当前时段最常用的应用，并在数据不足时使用相邻时段已有记录补足；常用区域呈现跨时段使用频率最高的应用。

没有历史数据时，GOTO 会明确告诉你“暂时没有可展示的记录”，不会用虚假应用填充。随着你真实使用，卡片会逐渐变成属于你的启动入口。

### 用设置调整体验，而不是学习一套系统

基本设置、个性化、无障碍和光感模式都以小范围调整为主。语言、时间显示、秒钟、主题、动画和卡片表现都可以在设置中改变；重置设置后，会回到清晰的默认状态，包括默认语言、12 小时制和关闭秒钟显示。

<button class="doc-inline-demo" data-preview-action="settings">在手机预览中查看设置</button>

光感模式只改变视觉氛围，不改变搜索结果和核心交互。它会根据设备环境提供更柔和的釉面、雾透和光照变化；无法取得位置权限时，使用时区进行保守估算。权限由系统弹窗说明，用户可以拒绝，基础搜索仍然可用。

### 让提醒出现在合适的时候

GOTO Where 是智能提醒层。它根据时间、当前应用和近期行为判断“现在是否适合提示”，并在获得系统通知权限后发送真实通知。它不会替你修改搜索输入，也不会凭空创造应用。

### 保留进阶能力，但不打扰首页

SuperGOTO 将进阶能力收纳在一个开关中。开启后，你可以逐步使用自适应刷新、GOTO Prethink 预处理、模糊匹配、元标签索引、模拟智能和超级语音等功能；关闭后，首页仍保持简洁。

GOTO Prethink 只负责在正式搜索前提出少量参考猜测，不改变你的原始输入。你仍然可以看到自己输入的内容，最终结果由搜索流程统一确认。详细的组件边界与调用方式请阅读《架构设计》，这里不把实现细节塞进用户介绍。

## 一套更稳的日常体验

### 真实应用，真实入口

Android 端读取设备上实际安装的应用、名称、图标和启动入口。GOTO 不内置一套与手机无关的假应用列表；在无法读取图标时，统一使用灰色占位，并保留真实名称和可用的启动状态。

### 适配不同屏幕

GOTO 面向手机、平板、折叠屏和 Flip 形态设计。页面会按照安全区和实际窗口尺寸调整，而不是在手机里再套一层固定网页。搜索框、卡片、状态栏和底部区域保持自己的边距规则，横竖屏切换时也尽量保持内容可读。

### 清楚的状态反馈

启动应用时会给出简短的“已启动”提示；没有结果、没有权限、没有统计数据和暂时无法读取图标时，分别使用不同的说明。动画有缓冲和阻尼，但不会阻塞输入或延迟打开应用。

### 本地优先与可控权限

应用列表、使用统计、设置和搜索历史优先保留在本机。需要通知、位置或应用信息时，GOTO 通过系统权限流程请求，并在没有权限的情况下保持基础功能可用。你可以在系统设置中随时收回权限。

## 文档与手机预览是联动的

右侧文档不仅是说明文字。部分章节提供“在手机预览中查看”入口，点击后会让左侧预览跳到对应页面或状态，帮助你把文字和实际体验对应起来。预览是文档站点中的展示层，Android 应用则使用同一套体验约定连接真实系统能力。

文档源文件位于 `Document/`，页面会将这些文件渲染成右侧内容。这样产品说明可以持续补充，页面样式也可以统一维护，而不需要把说明文字硬编码在页面脚本里。
